# Use Cases: Today

What Hermes can already do well, given its current scope (natural-language
control of Mail, Calendar, and Reminders via AppleScript, running locally).

- **Job search assistant** — track applications, flag rejections vs. active
  threads, summarize pipeline status on demand.
- **Inbox triage** — daily "what needs my attention" digest, surfacing
  unread mail from specific senders or domains.
- **Meeting/schedule assistant** — "what's my day look like," conflict
  checks, quick event creation from natural language.
- **Personal task capture** — turn a spoken or typed ask into a Reminder
  with a due date, without opening the app.
- **Daily briefing** — one combined summary of calendar + unread mail +
  reminders each morning.

See [PLAN.md](PLAN.md) for the design and [ROADMAP.md](ROADMAP.md) for
where this could go next.
